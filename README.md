## Introduction

This DeFi orderbook enables peer-to-peer token trading on the Stacks blockchain. Users can:

- Deposit tokens to the contract

- Create buy/sell orders

- Fill existing orders partially or completely

-  Cancel their own orders

- Query order status and user balances

## Features

 Limit Orders: Create buy/sell orders at specified prices
    
 Partial Fills: Fill orders partially, with remaining amount staying active

 Order Cancellation: Cancel active orders and unlock tokens

 Balance Management: Built-in token balance tracking

 Event Emission: On-chain events for order lifecycle tracking

 Read-only Queries: Check orders and balances without transactions
